# Asking Star Runtime Component

This is the local TGOSKits scheme-B import of the Asking Star runtime core.

For the functional layout and review boundary, see docs/docs/asking-star/scheme-b-overview.md.

Scope:

- `DigitalSet` record/view/ref resolver primitives
- GCYY runtime records and views
- V5.5 host-side smoke surfaces such as Walker-Giant, chamber/pouch, skin projection, and replay/RKNN runtime records

This component deliberately does not claim board execution. StarryOS coupling is routed through the sibling `asking-star-soil` component.
